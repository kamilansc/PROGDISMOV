# Abasteça Melhor ⛽

Aplicativo desenvolvido em Flutter para comparar os preços do álcool e da gasolina e indicar qual combustível está mais econômico.

## 📱 Sobre o projeto

O **Abasteça Melhor** recebe os valores do álcool e da gasolina informados pelo usuário e realiza um cálculo para determinar qual combustível escolher.

O cálculo utilizado é:

```text
(Valor do álcool / Valor da gasolina) × 100
```

## 🎓 Objetivo
Projeto desenvolvido como atividade prática de aprendizado de Flutter e Dart, trabalhando conceitos como:

- StatelessWidget
- StatefulWidget
- setState
- TextField
- TextEditingController
- Image.network
- SingleChildScrollView

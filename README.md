# Programação para Dispositivos Móveis

Repositório com atividades desenvolvidas para a disciplina de **Programação para Dispositivos Móveis**. Cada subpasta contém um projeto Flutter independente.

## Atividades

- `flutter_application_primeira_tela`: Aplicação com contador interativo e navegação entre uma tela inicial e uma lista.
- `flutter_application_simple_navigation`: Exemplo de navegação entre duas telas por meio de rotas nomeadas.
- `flutter_application_Abasteca_Melhor`: Aplicação que compara os preços do álcool e da gasolina informados pelo usuário para indicar a opção mais econômica.
- `flutter_application_My_Tasks`: Aplicação para cadastrar tarefas, atualizar seu status e consultar indicadores de acompanhamento.
- `flutter_application_My_Avaliations_Map`: Aplicação de mapa que permite selecionar locais e registrar avaliações com nota e comentário.

## Como executar

Em um terminal:

1. Acesse a pasta do projeto desejado:
   ```bash
   cd nome_da_pasta
   ```
2. Instale as dependências:
   ```bash
   flutter pub get
   ```
3. Execute o aplicativo:
   ```bash
   flutter run
   ```
